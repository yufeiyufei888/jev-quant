# 规则覆盖登记

首个标的是上交所主板普通股贵州茅台。已把交易所公告能确认的规则版本登记在 [`sse_mainboard_rules_v1.json`](../configs/sse_mainboard_rules_v1.json)：2023 版从 2023-04-10 起映射，2026 版从 2026-07-06 起映射；2023-01-01 至 2023-04-09 明确留作未覆盖区间。此登记只确认规则文本和生效日，不代表行情时间标签、历史证券状态或正式撮合已验收。

| 事项 | 代码/测试状态 | 正式历史回放状态 |
|---|---|---|
| T+1 批次可卖数量 | 已实现基础逻辑并有单元测试 | 待交易日历、除权与历史口径核验 |
| 整手开仓预算 | 已实现 100 股手数向下取整 | 上交所主板普通股规则已按日期登记；项目配置尚未替代交易引擎内的通用验证 |
| 限价保护与不利滑点 | 已实现价格保护接口 | 待历史规则和时间标签核验 |
| 佣金、印花税、过户费 | 佣金费率及最低佣金是实验假设；印花税、过户费按日期配置 | 印花税减半生效日已由官方通知交叉核验；佣金仍非统一法定费率，过户费官方原始依据尚需归档，故整体按模拟费用口径披露 |
| 涨跌停价格字段 | 用户日线 2023–2024 的 484 行均有涨跌停价；日线高低价均在边界内，边界与前收盘 ±10% 的分位算术核对 484/484 通过 | SSE 主板普通股 2023 版、2026 版规则和生效日已登记；字段供应商来源、2023-01-01 至 2023-04-09 规则衔接、历史ST/停牌状态和除权参考价仍未通过 |
| ST、停牌、上市/退市状态 | 已找到 2022–2026 茅台状态文件，数据行完整且与 2024+ 日历逐日对齐 | 文件标记非 PIT，不能作为历史时点资格门槛；生命周期仍需独立核实 |
| 停牌/涨跌停排队 | 缺少可信的逐日停牌队列/盘口，涨跌停触板时保守拒绝成交的接口已预留 | 不模拟排队优先权；停牌状态需 PIT 来源后才能正式回放 |
| 分红、送转 | 账户基本应收与股数比例事件接口 | 茅台历史事件、到账时间和税务未核验 |

早期报告必须标注“含模拟费用；个人红利税未模拟”，不得称为税后实盘收益。

## 已登记的规则依据

- [上交所2023年股票交易规则](https://www.sse.com.cn/lawandrules/sselawsrules2025/repeal/rules/c/c_20250612_10824490.shtml)按其生效条款在首批注册制主板股票上市时启用；首批相关股票于2023-04-10开始交易。此前区间尚未录入本版本规则表。
- [上交所2026年股票交易规则](https://www.sse.com.cn/lawandrules/sselawsrules2025/stocks/exchange/c/c_20260424_10816482.shtml)及[生效说明](https://www.sse.com.cn/aboutus/mediacenter/hotandd/c/c_20260424_10816474.shtml)确定2026-07-06切换；主板风险警示股票涨跌幅比例由5%调整为10%，普通主板股票仍为10%。
- 规则表仅适用于上交所主板普通A股的贵州茅台样例。佣金仍是策略实验的费用假设，不能解读为交易所统一费率；模拟收益统一标注为“零显性费用、含成交摩擦的模拟收益”。
