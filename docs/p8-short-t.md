# P8 多股票 T+1 短差诊断

本版本以 100 万元虚拟账户、5 只年初固定股票、50% 底仓、最多 30% 可用机动资金和 20% 安全现金研究做 T。每笔新短差约占账户权益 2%，最多同时存在 3 个周期。股票由年初前 20 个交易日的成交额选择；上市时长、价格、ST、停牌和公司行动来源均须检查。2023 年入选 `002603.SZ`、`000858.SZ`、`002317.SZ`、`000756.SZ`、`601012.SH`。

本地规则读取已闭合的 5 分钟 Bar，计算 12 Bar VWAP、ATR 和偏离 `z`；只在 `|z|≥1.25` 且预计扣费后价差至少 15bp 时提出新周期候选。每根 Bar 最多审核一个普通候选，JEV 每天最多审核 3 个。JEV 只回答 `EXECUTE` 或 `SKIP`；止损、到期和账户风险退出直接由规则执行。T+1、整手、5 分钟延迟、保护限价、5bp 或一价位不利滑点、同一 Bar 1% 成交量上限和日期费用均保留。科创板申报额外执行[上交所说明](https://edu.sse.com.cn/tib/qa/)中的单笔至少 200 股约束；2023 年实际入选的 5 只股票没有科创板股票。

最终纯规则账户比单纯持有底仓少 **886.91 元**，已实现短差周期利润为 **-6,395.67 元**。三个全年离线账户均触发 15% 回撤失败条件，纯规则账户虽达到平均每日约 1.5 笔短差成交的活跃度目标，盈利、对照及风控要求均未通过。因此不继续付费跑 JEV 全年，也不进入 2024 验证或前向模拟。已完成账户账目正确性检查，但经济验收失败。最终规则独立跑出的前 20 日账户与全年账户的同期订单、成交、周期、审核记录和逐日净值完全一致。

在修正底仓重复补仓和预计滑点前，曾做过 20 日真实 JEV 探索：56 次审核，11 次同意、43 次拒绝、2 次超时，旧版账户期末 988,967.92 元。由于规则已改变，这一结果**不能与上表最终版本比较，也不能证明 JEV 审核有增益**；旧运行产物保留在 `artifacts/p8/short-t-2023-jev-20d-r1`。本版本后续没有再向 JEV 付费发起请求。

2023 数据的 5 分钟标签被假设为 Bar 结束时刻，历史状态不是逐时点可得证据，公司行动来自 BaoStock 回顾性税前记录。因此以上均为回顾性诊断，不能称为实盘可执行收益。全年 5 只股票的分钟成交量与日线大体对平；14 个股票日期差 1—2 股，已作为源数据舍入差单独记录。

旧 P7 的 80% 茅台账户保留原运行结果；50% 账户停在 2023-05-30 检查点，因 API 超时未完成，不能拿它作全年对照。

## 运行

从项目根目录执行，`$dataRoot` 指向用户现有的行情总目录，`$supportRoot` 指向该目录内已有的 `project-data/股票项目-data`；代码只读这两个来源。

```powershell
$env:PYTHONPATH = 'src'
python -m jevquant.cli short-t --data-root $dataRoot --support-root $supportRoot `
  --start 2023-01-03 --sessions 242 --mode offline `
  --protocol configs/p8_short_t_v1.json --output artifacts/p8/new-offline-run
```

结果目录分账户保存 `decisions.jsonl`、`orders.jsonl`、`fills.jsonl`、`cycles.jsonl`、`nav.jsonl`、`summary.json` 与 `independent-audit.json`；总目录的 `manifest.json` 记录冻结股票池、配置、输入来源哈希、数据质量差异。最终完整离线复跑见 `artifacts/p8/short-t-2023-full-r6`：257 个输入文件哈希、零严重质量缺口、14 个 1—2 股舍入差。产物位于 Git 忽略的 `artifacts/`，不会进入公开仓库。
