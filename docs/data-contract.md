# 数据契约（P0 当前状态）

所有原始数据均由外部路径只读读取。规范化层保留来源文件和行定位，金额使用元、股数使用整数股、成交价格使用未复权原始价格。复权因子只允许在其可得时点被证明后用于特征。

## 已完成的茅台数据核验

- 贵州茅台日线文件有 5,908 行（2001-08-27 至 2025-12-31），无重复日期。74 行 OHLC、成交量或成交额为空，全部发生于 2002—2012 年；方案首个开发区 2023—2024 年有 484/484 行且无关键字段缺失。早期缺值保留为缺失，不影响当前开发区。成交量列以手记载，内部转换为股乘 100；成交额列以千元记载，转换为元乘 1000。
- 全量五分钟审计读取 1,032 个交易日分区（2022-01-04 至 2026-04-10）；每天均有茅台 49 行、无缺少标的、无重复时间标签、无结构性坏值。对全部 50,568 行，分区日期与行内日期一致。日期标签序列均为 `09:30`、连续交易标签 `09:35–11:30` 与 `13:05–15:00`。这验证了时钟标签，不验证供应商的区间起止定义。
- 原始分钟成交量有 7 个交易日实际按“手”记录，而其余日期按“股”。对这 7 个日期增加了按日期和原文件 SHA-256 绑定的 `0.01` 换算；源文件保持只读，哈希变化时换算拒绝执行。全部 1,032 天分钟成交股数现与用户日线或日线补充数据逐日精确匹配。
- 分钟成交额与日线只有 22/1,032 天精确相等；最大绝对差 191 元（2024-10-08），中位数 14 元，最大相对差约 0.000148bp。成交额仍标记为近似交叉核对，不假定差异只是浮点误差。
- 首条分钟记录开盘价与日线开盘价一致仅 525/1,032 个重叠日，因此 09:30 标签不能作为已验证的日线开盘记录。最后一条分钟收盘价在 969 个用户日线重叠日与日线收盘相差不超过 0.01 元；BaoStock 的 63 个补充日不计入这一统计。
- 用户日线覆盖 2001-08-27 至 2025-12-31，共 5,908 行、无重复日期；74 行 OHLC、成交量或成交额为空，仍须与逐日状态核对。成交量从手转换为股，成交额从千元转换为元。
- BaoStock 原始日线补充覆盖 2026-01-05 至 2026-08-21，抓取于 2026-08-22。该补充晚于行情发生时间，仅能用于回顾核对，不能证明历史时点可得。
- 五分钟文件目录止于 2026-04-10；不推断之后已有分钟数据。
- 旧版 2023—2024 研究包含茅台 484/484 个日期状态记录：均标记上市、非 ST、非停牌，但退市状态全为未知；可得时间由事后重建为当日 09:00、发布时间为空、抓取时间在 2026 年。该表可供对照与异常排查，不可作为严格历史可见状态。
- 旧包包含 3 笔茅台现金分红记录（每股 25.911、30.876、23.882 元），原来只标记为日期重建；另有每股 19.106 元特别分红的上交所实施公告。现已在新项目用公司/上交所官方实施公告逐笔复核 2023—2024 共 4 笔金额、登记日、除息日和发放日，保守可得时间及记账口径见 [`moutai-corporate-actions.md`](moutai-corporate-actions.md)。这只覆盖该研究窗口内识别出的现金分红，不证明其他类型公司行动及公告更正历史完整。
- `daily_total_return_features_asof` 以原始收盘价和已知且已除息的现金分红构造因果特征；同一日期重复记录会报错。20 日 CLI 样例已跑通。账本按登记日持仓快照计算权益、除息日确认应收、发放日转现金，重复事件回放幂等；独立对账器从成交和事件重新计算现金、股份及应收，能发现注入的 1 元/1 股差异。仍需在连续账户回放中验证。每日收盘可得时间 15:05 是模拟假设，供应商真实发布时间未知；这些新能力尚未用于策略或正式账户回放。

## 阻断正式历史回放的待核验项

1. `trade_time` 是区间开始还是结束，以及 09:30、15:00 记录对应集合竞价、连续竞价还是收盘记录，尚未找到供应商证据。时钟网格检查通过不等于语义通过；这些标签在证据取得前不用于正式撮合。
   同槽位过去 20 个完整交易日成交量的计算器已实现，但在标签语义确认前，不把原始标签直接认作可交易执行槽位。订单另存决策时点与到达时点；撮合只接受显式完整区间且 `interval_start >= arrival_at` 的bar，模拟成交时刻记为区间开盘。当前原始适配器不推导区间边界，因此原始茅台bar仍会被拒绝撮合。
2. 已有的 2023—2024 状态表是事后重建，退市状态未知，缺少可证明的发布时间；需取得/映射足以支持研究窗口的历史状态与交易日历证据。日期化交易规则表也未完成。
3. 2023—2024 四笔现金分红的官方金额和实施日已核对，并已接入特征层；仍需验证公告更正可得时间、税务模式、到账现金账本事件，并核验非现金公司行动及事件表完整性。
4. 日线复权因子的来源与历史可得时间未知；因果特征和正式长期回放暂不使用该因子。
5. 此次完整核验仅针对茅台，不代表全市场其他证券。金额有细小差异且需查明来源；74 行日线缺值仍未做状态归因。
