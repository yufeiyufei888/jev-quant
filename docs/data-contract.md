# 数据契约（P0 当前状态）

所有原始数据均由外部路径只读读取。规范化层保留来源文件和行定位，金额使用元、股数使用整数股、成交价格使用未复权原始价格。复权因子只允许在其可得时点被证明后用于特征。

## 已核实的本机样本

- 贵州茅台日线文件：`股票全量数据（日线）/600519.SH.csv`，5908 行，交易日 2001-08-27 至 2025-12-31，无重复交易日；其中 74 行 OHLC、成交量或成交额为空，尚未与逐日停牌状态核对，必须保留为缺值。成交量列以手记载，内部转换为股乘 100；成交额列以千元记载，转换为元乘 1000。
- 五分钟行情为按交易日分区的 Parquet，字段包括 `code, trade_time, open, high, low, close, vol, amount, date, pre_close, change, pct_chg`。抽查 2022、2023、2024、2025、2026-03、2026-04 的茅台文件均有 49 条记录，源标签从 09:30 到 15:00。
- 2024-01-02 样本中，五分钟成交量汇总为 3,215,644 股，与日线转换值完全一致；日线开盘价与首条分钟记录一致。分钟收盘价与日线相差约 0.00001 元；分钟成交额合计比日线多 20 元，因此本日金额尚未标为完全对账。这可能来自 Parquet 浮点精度，但尚未证明。该抽样不代表所有日期均已对账。
- BaoStock 原始日线补充分区里茅台代码是 `600519.SH`（不是 `sh.600519`），共 154 个交易日，覆盖 2026-01-05 至 2026-08-21；`adjustflag=3`，统一抓取时间为 `2026-08-22T03:58:53.956554+00:00`。这是事后抓取记录，可作回顾交叉检查，不能证明决策当时已可见；尚未接入正式行情适配器。
- 五分钟文件目录目前止于 2026-04-10。当前只能认定目录覆盖，不认定此后数据存在。
