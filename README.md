# JevQuant

JevQuant 是面向 A 股多标的、多账户的量化研究与模拟交易项目。JEV 根据冻结的数据快照作判断，独立的成交模拟与账本记录订单、成交、持仓、资金和净值。项目只使用虚拟账户，不连接真实券商。

首个单股票样例使用贵州茅台与100万元虚拟账户；平台也包含多股票 T+1 短差版本，不局限于该标的或账户规模。当前已有回顾性诊断结果，尚未形成通过验收的盈利策略或真实前向证据。

## JEV 在系统中做什么

- **单股票决策**：读取每根已闭合的5分钟 Bar，按账户状态选择 `BUY / WAIT` 或 `HOLD / SELL`。支持 `compact_v1` 紧凑输入，减少每轮重复发送历史价量。
- **多股票短差审核**：本地规则扫描5分钟行情并提出候选，JEV 只返回 `EXECUTE / SKIP`，不能更改方向、数量、价格或否决规则风险退出。每日最多3次审核。
- **用量控制**：相同且已验证的请求复用缓存；记录模型、输入输出 token 和估算费用。真实调用前要求 Usage 页面金额及时间戳，默认5美元账户级本地预算门会阻断预计超额请求。统计可能延迟，不能保证提供方账单绝不超额；不要并发运行其他付费调用程序。
- **失败处理**：无效响应、超时或 API 错误不生成交易；保留错误及未完成实验记录。

研究版本固定使用 `jev-1.13.0`；这不是对该模型目前可用性或预测能力的保证。离线测试和 Mock 示例不访问付费 API。

## 两种单股票成交模式

| 模式 | 用途 | 处理方式 |
|---|---|---|
| `delayed_bar_open` | 研究延迟及成交摩擦的影响 | 决策后5分钟到达，保留保护价、滑点、成交条件和流动性限制 |
| `instant_snapshot_close` | 分析 JEV 判断本身的作用 | 按 JEV 当次看到的闭合 Bar 收盘价成交，去掉延迟、滑点和流动性限制 |

两种模式都保留资金、整手、模拟显性费用及 T+1。即时快照模式是理想化归因诊断，不能当作可执行的实盘收益。多股票短差版本沿用独立的延迟成交规则。模式结果分别报告，不混合比较。

## 已完成与尚未通过

- 账本、T+1、分红应收款、订单冻结、费用、独立对账、请求缓存和恢复链路已有合成案例及108项离线测试。
- 已完成单股票历史数据检查、基准账户诊断及1日、20日 JEV 样本；模型买入偏少的提示词诊断保留在文档中。
- 2023年多股票短差的底仓、纯规则和 Mock 账户完成了账目对账，但均亏损且最大回撤超过15%，**经济验收失败**。没有据此继续付费全年 JEV、2024验证或前向模拟。
- 旧50%单股票账户停在2023-05-30超时检查点，是未完成实验。
- 分钟标签、历史可得时间、证券状态及部分规则/公司行动仍有证据限制，结果属于回顾性诊断，不是盲测、实盘收益或盈利证明。模拟计入显性费用和成交摩擦，个人红利税未模拟。

## 安装与离线运行

需要 Python 3.11。Windows PowerShell 示例：

```powershell
py -3.11 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.lock
python -m pip install -e . --no-deps
python -m pytest -q
jevquant offline-demo
jevquant mock-round-trip --output artifacts/mock-round-trip
```

`mock-round-trip` 使用合成行情和 Mock 决策，演示买入、次日卖出和账户核算，不需要 API Key 或本地股票数据。生成文件留在 Git 忽略的 `artifacts/`，不属于公开内容。

## 本地数据与真实 JEV 接入

行情总目录通过 `JEVQUANT_DATA_ROOT` 或命令行参数指定；原始数据只读使用，不随仓库分发。具体字段、单位和覆盖要求见数据契约。

JEV 凭据通过 `TYPESAFE_API_KEY` 环境变量提供，或用 `JEVQUANT_TYPESAFE_ENV_FILE` 指向私有密钥文件。`.env.example` 只包含空白配置项；真实 `.env` 和密钥不得提交。

单股票真实调用方式见 [P6 文档](docs/p6-sample.md)。多股票版本默认 `--mode offline`，具体命令和输入要求见 [P8 文档](docs/p8-short-t.md)。运行真实接口会产生费用，必须单独配置凭据、确认数据发送及最新预算基线；安装、测试和离线示例不会自动开启真实调用。
